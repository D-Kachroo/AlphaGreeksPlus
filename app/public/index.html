The 5 Greeks

Use these metrics to understand the main risks before you trade options.

Delta How much the option changes when the stock moves $1.
Gamma How fast Delta changes when the stock moves.
Theta How much value the option loses daily.
Vega How much the option changes when volatility moves.
Rho How much the option changes when interest rates move.
